# 变更记录 — 2026-05-11（0511）

## 更新 0510_3 → 0511_0

**摘要：** 一次 **大规模的乘法器数据通路重写**。卷积乘法器（`conv_mul`）被改写为
「高位拼接」的 MAC 优化结构：将 8bit 被乘数 A、8bit 零、8bit 被乘数 B 依次拼接后与 8bit
乘数 C 相乘，借助乘法分配律一次得到 16bit `C·A` 与 16bit `C·B` 的拼接，可直接映射为紫光
**APM_E2** 原语，大幅降低 MAC（DSP）资源占用。同时新增 *有符号* 量化缩放乘法器变体
（`*_s3`，对应量化系数 s₁s₂/s₃ 的乘法）。本次构建的资源占用骤降（APM/DSP → 0，LUT → 约
10K）——完整 NPU 在下一个版本（0511_1）中被恢复。

> APM、DRM、LUT、FF、DistRAM 全面下降到约 25%，说明该构建只编译了 NPU 的一部分逻辑
> （属于重写过程的中间状态），而非常态配置。技术文档所述 MAC 优化最终仍是映射到 DSP
> （APM_E2），只是用一次乘法同时得到两个乘积，从而降低 MAC 资源占用——这与 0511_1 中
> APM 从 224 降至 196 的趋势一致。
