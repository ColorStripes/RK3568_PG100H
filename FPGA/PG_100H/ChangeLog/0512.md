# 变更记录 — 2026-05-12（0512）

> **背景**：`conv_in_ctrl` / `conv11_in_ctrl` / `sppf_in_ctrl` 等属于 NPU 的「数据输入模块」，
> 负责在输入缓冲与控制模块之间统筹调度——数据进入输入缓冲后由控制模块判断是否符合计算条件，
> 再送入循环缓冲或计算模块。本日集中微调这批输入控制器。

## 更新 0511_2 → 0512_0

**摘要：** 对卷积与 NPU-CDC 模块的输入控制器进行微调，并更新 PCIe 约束。时序略有回退
（setup 裕量 2.029 → 0.948）。

### 源码变更

**修改**
* `source/npu/conv/conv_in_ctrl.v`
* `source/npu/conv11_16/conv11_in_ctrl.v`
* `source/npu/npu_cdc_top.v`
* `source/top.v`
* `source/constraints/pcie.fdc`

### 资源与时序

|---|---|---|
| LUT | 43,350 | 43,339 |
| FF | 42,558 | 42,834 |
