# 变更记录 — 2026-07-04（0704）

## 更新 0601_0 → 0704_1

**摘要：** **引入 HDMI 视频输入子系统**，项目更名为 `yolo_fpga_hdmi_ov5640`。新增
`source/HDMI/` 目录树（MS72xx HDMI 收发器控制、`iic_dri.v` IIC 接口逻辑）和 `clock.fdc` 约束，实现
**720p OV5640（DVP）与 1080p HDMI（TMDS）双输入源**支持。顶层增加互斥的
`USE_OV5640` / `USE_HDMI` 编译开关；**本次构建运行在 HDMI 输入模式**（摄像头与 NPU 未编译），
因此占用极小（约 9.5K LUT、零 DSP）。

### 源码变更

**新增**
* `source/HDMI/hdmi_top.v`、`hdmi_loop.v`、`iic_dri.v`、`ms7200_ctl.v`、`ms7210_ctl.v`、
  `ms72xx_ctl.v`
* `source/constraints/clock.fdc`

**修改**
* `source/top.v` — 新增 `` `define USE_HDMI`` / `` `elsif USE_HDMI`` 代码块；新增端口
  `rstn_out`、`iic_scl`、`iic_sda`，以及并行 RGB 视频输入 `pixclk_in`、`vs_in`、`hs_in`、
  `de_in`、`r_in`、`g_in`、`b_in`；例化 `hdmi_top`。
* `source/npu/npu_cdc_top.v`
* `source/ov5640/ov5640/ov5640.v`、`ov5640_cdc.v`、`ov5640_top.v`
* `source/constraints/cdc.fdc`、`ddr3.fdc`、`ov5640.fdc`、`pcie.fdc`
