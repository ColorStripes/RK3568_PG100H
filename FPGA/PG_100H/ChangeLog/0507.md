# 变更记录 — 2026-05-07（0507）

## 更新 0507_0 → 0507_1

**摘要：** 对 NPU 卷积数据通路做了一次整理——乘法模块被合并，1×1 卷积输出通道并行度减半。
资源用量与时序均无变化，因此这本质上是一次清理 + 小幅参数修改，而非功能性重设计。
